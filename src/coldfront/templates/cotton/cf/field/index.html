{% comment %} Unified form field renderer. Wraps a bound field's control in a label/help/errors layout. The control itself is rendered by Django's own widget template via render_field_with_aria, which wires WAI-ARIA (aria-describedby / aria-invalid) + the daisyUI error class onto the control and mirrors field data onto Alpine select widgets. The trio (Alpine combobox select, toggle, date picker) lives in their widget templates (widgets/alpine_select.html, django/forms/widgets/{checkbox,date,datetime,time}.html). Props: field the bound field (BoundField) layout "inline" (label left, control right, default) or "stacked" nullify if true and field.name in form.nullable_fields, render the nullable (set-to-None) checkbox alongside the field show_label render the label (default true) show_help render help_text (default true) show_errors render field errors (default true) wrapper_class extra classes on the wrapper label_class extra classes on the label control_class extra classes on the control wrapper Render: every bound field's control is rendered by Django's own widget template via render_field_with_aria, which wires ARIA + the daisyUI error class onto the control and mirrors field data onto Alpine select widgets.
